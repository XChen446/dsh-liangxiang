## 日终并发

使用真实 Ed25519 签名、HTTP、文件 SQLite/WAL，未访问正式社区或放宽默认限额。

- 先为 1000 个独立客户端建立各自连接，再于同一业务秒同时释放投票，各 20 炷；1000 个连接、20,000 炷、1000 位香客，全量重放不再次扣香。
- 100 户手动/自动共享余额并重复提交；64 户的 2176 次最后一炷竞争；500 炷请求按预算压到 50、重放与冲突；128 个跨日旧案；32 个真实 Host 自动链路均通过。
- 新增慢刷新/落盘期间真正插入手动请求、100 手动请求争一炷、完成标记保存失败后重试、偏好和余额变化、关闭开关、截止与跨日回归。
- 账本、票据、总香火与唯一香客守恒，无超支、重复扣香、500 或锁库错误。2176 意图场景限制为 128 条在途连接；不把准备的请求数写成同时建立的连接数。
- 本机 1000 户实测样本约 320ms，p95 307.8ms；重放约 243ms。连接建立不计入该样本；此为单进程本机样本，不是冷连接、公网/TLS/生产峰值容量保证，未验证多个后端进程共享限流。

详细边界与复跑入口见 [日终并发验证](DAY_END_CONCURRENCY.md)。
