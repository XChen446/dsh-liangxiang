# 梁相 1.2.0

1. 梁子添新相：梁位低于 25% 显出小难梁，25% 到不足 50% 仍是梁工。
2. 拍梁子更有趣：单击轻快开合，双击吐槽，句句轻落、淡去。
3. 攒香更准确：请求用量各算各的，Pro 一倍，Flash 与其他模型半倍。
4. 日终不忘上香：可选 23:59 自动倾炉，右键夯或拉就能设默认方向；适配 DSH 新版。
